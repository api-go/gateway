添加证书

证书名称自动使用证书覆盖的域名，无需填写。上传证书自动读取 SAN 域名，无需手填；建议上传包含中间证书的完整证书链，证书文件的内容应为 BEGIN CERTIFICATE；私钥通常为 .key，内容应为 BEGIN PRIVATE KEY / RSA PRIVATE KEY / EC PRIVATE KEY，不能把证书文件传入私钥栏。扩展名仅作提示，内容校验为准。私钥须与证书匹配。私钥加密保存且不回显。泛域名证书无需额外开关：*.example.com 只覆盖 api.example.com 等一层子域名，不覆盖 example.com 或 a.b.example.com；根域名须单独包含在 SAN 中。自动申请需手填明确域名，目前不支持泛域名。自动证书保存后开始申请，进度和错误可在事件中查看。

自动签发设置

已内置 HTTP-01 验证与自动续期，无需额外安装组件。域名必须指向此节点，公网 80 端口须能转发到 HTTP 监听。本地 1080/10443 可用于上传证书验收；自动签发目前限单节点、非通配 DNS 域名。

会话保持规则

按进入网关时的路径与 HTTP 方法匹配，第一条符合的规则生效；未匹配时不启用。/* 匹配整站，/ 仅首页。仅影响服务发现代理；多个规则互相独立。

自动保持在本地分配并查表，后台批量同步，不等待 Redis；极短时间并发或节点视图不一致时允许首次归属冲突，已有有效映射不会被覆盖。纯哈希不保存分配表；渐进哈希共享 4096 分片表，优先迁移低负载分片，但不能保证旧会话零漂移。

代理

重写 / 重定向共用一个阶段，最先执行；然后代理，再处理静态目录。同阶段按保存顺序使用第一条匹配规则，具体规则应放在整站规则之前。

请求额度

设置适用条件、周期和允许次数即可；默认所有匹配请求合计。

每条规则独立计数，任何一条拒绝规则超额都返回 429，不排队。默认所有匹配请求合计；需要每个 IP 或 Session 各有一份额度时再修改计数方式。周期从第一条匹配请求开始。

定时检查

从 Gateway 检查已发布 Host 的上游，每次 GET、不跟随跳转。默认首页 /、HTTP 2xx/3xx 视为可访问、每 60 秒一次；不消耗网关请求额度。已发布的代理 Host 默认启用，服务启动后自动开始；可取消勾选并发布以停止监控。

高级响应检查（低代码）

HTTP 状态、包含文本与低代码判断均须通过。函数接收 {status, body, contentType, durationMS, truncated}，必须返回 true；body 为前 4096 字节，运行最多 5 秒。

报警通道、适用Host及连续失败阈值在监控模块的“报警通道”集中配置，无需在Host逐个绑定。报警直接使用本监控的检查结果，不另计时或重新累计失败。保留最近 10 次检查、最近 24 小时及最近 30 天统计，手动业务测试只作为本节点的最近测试状态。
